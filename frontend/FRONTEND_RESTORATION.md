## 🎨 界面特性

### Dashboard 布局
```
┌─────────────────────────────────────────────────────────┐
│  [Sidebar]  │  [Header: 质检看板 + 通知]                │
│             ├─────────────────────────────────────────────┤
│  - 首页     │  [筛选栏]                                  │
│  - 质检看板 │  - 时间范围                                │
│  - 上传视频 │  - 教师姓名 / 学员ID                       │
│  - 人工质检 │  - 检测状态 / 是否违规 / 违规分类筛选     │
│             │                                             │
│             │  [工具栏]                                  │
│             │  共 X 条记录        [列表] [卡片]          │
│             │                                             │
│             │  [数据视图 - 列表或卡片]                   │
│             │  ┌─────────────────────────────────────┐  │
│             │  │ 封面 | 课程信息 | 状态 | 标签 | 操作 │  │
│             │  └─────────────────────────────────────┘  │
│             │                                             │
│             │  [分页]                                    │
│             │  显示 20 条/页  [1] [2] [3] [4] [5]       │
└─────────────────────────────────────────────────────────┘
```

## 📝 注意事项

### 后端字段映射
由于后端暂无以下字段，使用了默认值：
- `screenshot` → 使用 `frame_urls[0]` 或占位图
- `videoLink` → 使用 `original_video_url`
- `coverStatus` → 默认 `'pass'`
- `violations` → 从 `evaluations` 中提取
