# 批量上传调试说明

## 问题排查步骤

### 1. 查看浏览器控制台

打开浏览器开发者工具（F12 或 右键 → 检查），切换到 Console 标签，查看：

```
解析到的表头: ['学员ID', '教师姓名', '上课时间', '视频链接']
数据行数: 2
字段索引: {studentIdIdx: 0, teacherNameIdx: 1, classTimeIdx: 2, videoLinkIdx: 3}

第 2 行: {
  studentId: '61519403',
  teacherName: '吴亚男',
  classTimeRaw: 45992.375,  // Excel 数字格式
  classTime: '2025/12/01 09:00',  // 转换后的时间
  videoLink: 'https://...'
}
```

### 2. Excel 日期格式处理

**问题：** Excel 中的日期被存储为数字（从 1900/1/1 开始的天数）

**解决：** 使用 `XLSX.SSF.parse_date_code()` 自动转换

**示例：**
- Excel 存储值：`45992.375`
- 转换后：`2025/12/01 09:00`

### 3. 常见失败原因

#### a) 时间格式错误
**错误信息：** "时间格式错误: xxx"

**解决方案：**
- 确保 Excel 中的时间列格式为"日期时间"类型
- 或者使用文本格式：`2025/12/01 9:00`

#### b) 视频链接格式错误
**错误信息：** "Input should be a valid URL"

**解决方案：**
- 确保链接以 `http://` 或 `https://` 开头
- 示例：`https://record-ali.51talkjr.com/...`

#### c) 必填字段为空
**错误信息：** "跳过第 X 行：数据不完整"

**解决方案：**
- 检查该行是否有空单元格
- 确保所有必填字段都有值

### 4. 查看失败详情

上传完成后，在"最近上传记录"表格中：
- 状态列会显示"失败"徽章（红色）
- 下方会显示详细的错误信息
- 将鼠标悬停在错误信息上可以看到完整内容

## 正确的 Excel 格式

| 学员ID | 教师姓名 | 上课时间 | 视频链接 |
|--------|---------|---------|---------|
| 61519403 | 吴亚男 | 2025/12/1 9:00 | https://... |
| 11078524 | 吴欣韵 | 2025/12/1 10:00 | https://... |

**注意：**
- 第一行必须是表头
- 列顺序可以任意
- 日期可以是 Excel 日期格式或文本格式
- 视频链接必须是完整的 URL

## 测试建议

1. 先用 1-2 条数据测试
2. 检查控制台输出
3. 确认数据解析正确
4. 再上传完整数据
